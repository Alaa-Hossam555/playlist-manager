playlist manager

describtion:
-managing and storing songs and podcasts
-search of song or podcast by title
-filter library by artist or genre
-sort by title or duration or play count
-managing playlist using next and previous tracks
-up next queue
-tracking how many the song or podcast  was played in playlist or in queue
-calculating duration of playlist
-most 5 played songs

OOP concepts
-abstraction
-inheritance
-polymorphism
-encapsulation
-virtual  functions
-dynamic memory allocation
-destructor
-operator overloading




data structures:
-Array for the media library
-doubly linked list
-queue


algorihtms
-binary search
-linear search
-selection sort
-recursion


big(o)
| Add to Library > O(1) 
| Delete from Library > O(n) 
| View Library > O(n) 
| Linear Search > O(n) 
| Binary Search > O(log n) 
| Selection Sort > O(n²) 
| Add to Playlist > O(n) 
| Remove from Playlist > O(n) 
| Total Playlist Duration > O(n) 
| Add to Queue > O(1) 
| Play Next from Queue > O(1) 
| Top 5 Most Played > O(n²) 



Project Structure
 MediaItem — Abstract base class
 Song — Represents songs
 Podcast — Represents podcasts
 LibrarySystem — Manages the media library
 Playlist — Manages the doubly linked list
 Queue — Manages the Up Next queue
